# rootforce.dev

Мультиязычный лендинг на Next.js (App Router) и React. Страницы предварительно рендерятся в HTML; форма брифа и визуальные эффекты работают в браузере.

Английский — основной язык (`/`), немецкая версия доступна по `/de/`, русская — по `/ru/`. Выпадающий список в хедере переключает язык с сохранением текущего раздела. Каждая версия имеет собственные `lang`, заголовок, описание, canonical и ссылки `hreflang`.

Юридические страницы: `/impressum/` и `/datenschutz/`, также с префиксами `/de/` и `/ru/`. Ссылки доступны в футере каждой страницы. На юридических страницах выбор языка сохраняет документ и текущий раздел; декоративные эффекты не запускаются.

Форма открывает почтовый клиент через `mailto:` с письмом на `lkam1hunt@gmail.com`, заполненными темой и описанием проекта. Пользователь отправляет письмо из своего почтового клиента.

## Разработка

Требуется Node.js 20.9 или новее (рекомендуется актуальная LTS-версия).

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Production

```sh
npm run build
npm start
```

Сборка создаёт статический сайт в `out/`. Команда `npm start` обслуживает эту папку. Для публикации загрузите содержимое `out/` на статический хостинг. `.openai/hosting.json` указывает на эту папку и сохраняет прежний идентификатор сайта.

Используется `output: 'export'`: Node.js на хостинге не требуется. Для серверных API или Server Actions потребуется изменить режим сборки и хостинг.

## Структура

- `app/(english)/` — страница и корневой layout английской версии.
- `app/[lang]/` — статические страницы и корневой layout немецкой и русской версий.
- `components/Landing.jsx` — общий шаблон страницы.
- `components/LanguageSelect.jsx` — выбор языка в хедере.
- `components/LegalPage.jsx`, `components/LegalPage.css` — читаемый шаблон юридических документов с оглавлением и стилями печати.
- `components/SiteFooter.jsx` — общий футер со ссылками на юридические страницы.
- `lib/legal.js` — реквизиты владельца и тексты юридических документов на трёх языках.
- `lib/i18n.js` — переводы, адреса языковых версий и метаданные.
- `app/globals.css` — исходные стили в прежнем порядке каскада.
- `components/Brief.jsx` — диалог с формой и открытием черновика письма через `mailto:`.
- `components/Flowers.jsx` — SVG-цветы.
- `components/VisualEffects.jsx` — жизненный цикл визуальных эффектов.
- `lib/ascii.js` — ASCII-след курсора; холсты создаются при первом движении мыши в разделе.
- `components/Cloudscape.jsx`, `public/images/` — готовая облачная текстура в AVIF и WebP.
- `scripts/generate-cloud-texture.mjs` — воспроизводимая генерация текстуры вне браузера (`npm run assets:clouds`). Готовые файлы включены в проект, при обычной сборке генерация не нужна.
- `app/fonts.js` — шрифты через `next/font`: файлы загружаются при сборке и обслуживаются с сайта.
- `public/serve.json` — годовой кэш для ресурсов `/_next/static/` с хэшем в имени при запуске через `npm start`.
- `components/BrandMark.jsx` — восьмилучевой геометрический знак в хедере, первом экране и футере.
- `app/icon.svg`, `app/favicon.ico` — favicon с фирменным знаком и мягким градиентом.
- `public/brand/rootforce-symbol.svg` — отдельный векторный знак на прозрачном фоне.
- `dist/` — сохранённая исходная статическая версия; Next.js её не использует. Все дальнейшие изменения вносите в `app/`, `components/` и `lib/`.

При посещении сайта нет запросов к Google Fonts. Анимации учитывают `prefers-reduced-motion`; при сенсорном вводе холсты следа курсора не создаются. Появление следа по-прежнему занимает около 0,3 секунды. При анимации очищается только область следа, а не холст всего раздела.

Для проверки Lighthouse используйте production-сборку: `npm run build`, затем `npm start`. Проверка `npm run dev` включает служебные скрипты разработки и не отражает скорость публикуемого сайта. На другом статическом хостинге настройте длительное кэширование `/_next/static/` на его стороне; `serve.json` применяется локальным сервером `serve`.

# rootforce.dev

Лендинг на Next.js (App Router) и React. Страница предварительно рендерится в HTML; форма брифа и визуальные эффекты работают в браузере.

## Разработка

Требуется Node.js 20.9 или новее (рекомендуется актуальная LTS-версия).

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Production

```sh
npm run build
npm start
```

Сборка создаёт статический сайт в `out/`. Команда `npm start` обслуживает эту папку. Для публикации загрузите содержимое `out/` на статический хостинг. `.openai/hosting.json` указывает на эту папку и сохраняет прежний идентификатор сайта.

Используется `output: 'export'`: Node.js на хостинге не требуется. Для серверных API или Server Actions потребуется изменить режим сборки и хостинг.

## Структура

- `app/page.jsx` — содержимое страницы.
- `app/layout.jsx` — корневой layout, язык и метаданные.
- `app/globals.css` — исходные стили в прежнем порядке каскада.
- `components/Brief.jsx` — диалог и скачивание текстового брифа без отправки данных на сервер.
- `components/Flowers.jsx` — SVG-цветы.
- `components/VisualEffects.jsx` — жизненный цикл визуальных эффектов.
- `lib/` — ASCII-след курсора и генерация облачной текстуры.
- `dist/` — сохранённая исходная статическая версия; Next.js её не использует. Все дальнейшие изменения вносите в `app/`, `components/` и `lib/`.

Шрифты, как и в исходной версии, загружаются через Google Fonts. Анимации учитывают `prefers-reduced-motion`.
